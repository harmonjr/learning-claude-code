# Learning Claude Code for Real Estate Applications

This repository documents my journey mastering Claude Code and the Claude Agent SDK, with a specific focus on real estate industry applications.

## Purpose

This learning repository serves as:
- A structured workspace for experiments and skill development
- Documentation of Claude Code capabilities and best practices
- A library of reusable skills, scripts, and automation tools
- A collection of real estate-specific use cases and examples
- Course materials and video scripts for teaching others

## Repository Structure

### `00-research-notes/`
Research and documentation about Claude Code, its features, and capabilities.
- `claude-code-features.md` - Feature exploration and notes
- `skills-documentation.md` - How skills work and best practices
- `github-integration-notes.md` - Git workflows and integration patterns

### `01-git-fundamentals/`
Git and GitHub fundamentals practice.
- `practice-exercises/` - Hands-on exercises for Git operations
- `notes.md` - Key learnings and command references

### `02-skills-library/`
Collection and analysis of Claude Code skills.
- `installed-skills/` - Skills installed from the marketplace
- `custom-skills/` - Custom skills I've created
- `skills-analysis.md` - Notes on skill architecture and patterns

### `03-market-intelligence/`
Real estate market research and intelligence gathering.
- `neighborhood-profiles/` - Automated neighborhood analysis
- `market-reports/` - Market trend reports and data analysis
- `competitive-analysis/` - Competitive market intelligence

### `04-marketing-content/`
Marketing content generation and management.
- `social-media/` - Social media post templates and automation
- `email-campaigns/` - Email marketing content and sequences
- `listing-packages/` - Property listing descriptions and materials
- `blog-posts/` - Blog content for real estate topics

### `05-automation-scripts/`
Automation tools and scripts for real estate workflows.
- `python-scripts/` - Python automation scripts
- `workflow-templates/` - Reusable workflow templates and patterns

### `06-video-course-materials/`
Educational content for teaching others about Claude Code.
- `video-scripts/` - Scripts for tutorial videos
- `course-outlines/` - Course structure and curriculum
- `agent-examples/` - Example agent implementations and demos

### `99-sandbox/`
Experimental workspace for testing and exploration.
- `experiments/` - Quick tests and proof-of-concept work

## Learning Goals

1. **Master Claude Code fundamentals** - File operations, Git integration, tool usage
2. **Create custom skills** - Build reusable skills for real estate workflows
3. **Develop automation** - Streamline repetitive real estate tasks
4. **Generate marketing content** - Leverage AI for listings, social media, and campaigns
5. **Build market intelligence tools** - Automate research and analysis
6. **Document and teach** - Create course materials to help others

## Getting Started

To use this repository effectively:
1. Start with research notes to understand Claude Code capabilities
2. Practice Git fundamentals in the dedicated folder
3. Explore and install useful skills from the marketplace
4. Begin creating custom skills for specific real estate needs
5. Build automation scripts for common workflows
6. Document everything and create teaching materials
